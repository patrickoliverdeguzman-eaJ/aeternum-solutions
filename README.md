# Aeternum Solutions

Public website for Aeternum Solutions, featuring SaaS systems, digital business benefits, contact links, and a portfolio placeholder.

## Edit the website

- Page content: `dist/index.html`
- Styles: `dist/styles.css`

Changes pushed to `main` are automatically published to GitHub Pages by the Deploy website workflow.

The `.openai/hosting.json` file retains the separate Sites hosting configuration. GitHub Pages publishes only `dist`.
